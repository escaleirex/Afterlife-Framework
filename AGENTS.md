# Agent Guide (Cursor / Automation)

This repository is documentation-first. Agents must follow `.cursor/rules/`.

## Quick Mandates

1. **Read the [Constitution](docs/00-vision/Afterlife-Framework-Constitution.md) first.** It is foundational project law. Do not violate it.
2. Read `docs/index.md` before architectural decisions.
3. Obey `ROADMAP.md` phase gates.
4. Do not invent systems not documented—RFC first.
5. No core quest/objective ontology (Constitution Article III).
6. No proprietary IP in core.
7. Event Bus + Registries + server authority are mandatory patterns.
8. Update docs + `CHANGELOG.md` with behavior changes.
9. Prefer extensibility for mappers and modders.
10. Prefer Afterlife Hub over third-party workshop lock-in (Article XIII).
